# AltSource Studio

[AltStudio](https://altstudio.app/)의 AltSource 편집 흐름을 참고해 만든 독립형 SwiftUI iOS 앱입니다. JSON 저장 시 NightFox_Repository의 소스 변환 규칙에 맞춰 출력합니다.

## 기능

- 사진과 같은 순서로 소스 이미지, 색상, 이름, 설명, 링크, 추천 앱 편집
- 이미지 URL 미리보기와 사진 선택 미리보기 지원. 선택한 로컬 사진은 JSON에 포함되지 않으므로 배포용 이미지 URL을 별도로 입력해야 합니다.
- 소스 화면의 **View code**에서 JSON 미리보기로 이동하고, 추천 앱을 검색·선택·정렬할 수 있습니다.
- 앱과 버전, iPhone/iPad 스크린샷, 권한 편집
- 앱 탭에서 아이콘·틴트 색상이 보이는 카드 목록을 검색하고 앱별 편집 화면에서 스크린샷, 버전, 개인정보 권한, Entitlements를 관리
- 버전 추가 창에서 IPA/ADP 다운로드 URL, 크기 단위, 출시일 등을 입력. 기기 파일을 고르면 파일 크기를 자동 입력하며 배포 URL은 직접 입력해야 합니다.
- 뉴스 항목 편집
- 기존 AltSource JSON 가져오기, 실시간 JSON 미리보기, 파일로 저장
- JSON 파일 선택 시 `.json` 형식만 허용하고, 가져오는 동안 경과 시간과 로딩 표시
- 필수 입력 항목과 중복 식별자 확인
- 작업 내용 기기 내 자동 저장
- iPad의 넓은 화면에서는 사이드바와 편집 화면을 나란히 표시하고, 좁은 창에서는 탭 화면으로 전환
- 앱을 열면 시작 화면에서 새 프로젝트, 이전 작업 계속하기 또는 기존 JSON 가져오기를 선택
- 입력 화면에서 키보드 위의 **키보드 내리기** 버튼으로 입력 종료
- JSON 저장 시 버전 최신순 정렬, 날짜 `+09:00` 형식, 누락된 최소 iOS 버전 `16.1` 보정, NightFox GitHub 릴리스 URL의 프록시 주소 변환

## 사용법

1. **소스** 탭에서 이름을 입력합니다.
2. **앱** 탭에서 앱과 최소 하나의 버전을 추가합니다. 다운로드 URL은 게시된 IPA 또는 ADP 파일을 가리켜야 합니다. 크기는 바이트 단위입니다.
3. 필요하면 **뉴스**를 추가합니다.
4. **JSON** 탭에서 검증 메시지를 확인하고 **JSON 저장**을 누릅니다. 기존 JSON은 같은 탭의 **가져오기**에서 열 수 있습니다.

이 앱은 JSON 파일을 생성합니다. 생성한 JSON과 실제 IPA/ADP는 사용자가 별도로 호스팅해야 AltStore 소스로 배포할 수 있습니다.

## 빌드와 설치

- Xcode에서 `AltSourceStudio.xcodeproj`를 엽니다.
- 배포 대상: iOS 17 이상.
- 제공된 IPA는 코드 서명 및 프로비저닝이 없는 빌드입니다. AltStore 등에서 기기용으로 서명해 설치하거나 Xcode에서 자신의 개발 팀을 선택해 다시 빌드하세요.
- 터미널에서는 `./scripts/build-ipa.sh`로 서명되지 않은 IPA를 `build/AltSourceStudio.ipa`에 만들 수 있습니다.
- GitHub의 **Actions → Build unsigned IPA**에서 `main`에 푸시하거나 수동 실행하면 IPA를 실행 아티팩트로 받을 수 있습니다.

## 범위

AltStudio 웹사이트의 IPA/ADP 자동 스캔과 온라인 이미지 업로드는 포함하지 않았습니다. 해당 정보는 편집 화면에서 직접 입력합니다. 가져온 JSON의 추가 필드는 편집 중에도 가능한 한 보존하며, NightFox 변환 규칙에서 제거하는 필드(`website`, `patreonURL`, `marketplaceID`, `buildVersion`, 뉴스 `url` 등)는 저장 결과에서 제외합니다.
