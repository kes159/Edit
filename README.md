# Source Editor

SideStore용 소스 JSON을 만들고 관리하는 SwiftUI iOS 앱입니다. JSON 저장 시 소스 변환 규칙에 맞춰 출력합니다.

## 기능

- 사진과 같은 순서로 소스 이미지, 색상, 이름, 설명, 링크, 추천 앱 편집
- 이미지 URL 미리보기와 사진 선택 미리보기 지원. 선택한 로컬 사진은 JSON에 포함되지 않으므로 배포용 이미지 URL을 별도로 입력해야 합니다.
- 소스 화면의 **View code**에서 JSON 미리보기로 이동하고, 추천 앱을 검색·선택·정렬할 수 있습니다.
- 앱과 버전, iPhone/iPad 스크린샷, 권한 편집
- 앱 탭에서 아이콘·틴트 색상이 보이는 카드 목록을 검색하고 앱별 편집 화면에서 스크린샷, 버전, 개인정보 권한, Entitlements를 관리
- 앱 카드는 길게 눌러 순서를 바꾸고, 편집 모드의 3줄 손잡이는 누른 채 바로 드래그해 순서를 변경. 소스 탭에서 선택한 대표 앱의 손잡이도 바로 드래그 가능
- 앱 편집 화면에서 IPA/ADP 파일을 고르면 앱 이름, 번들 ID, 버전, 빌드 번호, 최소 iOS 버전, 파일 크기와 아이콘을 자동으로 읽습니다. 추출한 아이콘은 앱 안에서 미리 보고 PNG로 저장할 수 있습니다. 배포용 다운로드 URL과 공개 아이콘 URL은 직접 입력해야 합니다.
- 뉴스 항목 편집
- 기존 Source JSON 가져오기, 실시간 JSON 미리보기, 파일로 저장
- JSON 파일 선택 시 `.json` 형식만 허용하고, 가져오는 동안 읽은 파일 양에 따른 0~100% 진행 막대 표시
- 필수 입력 항목과 중복 식별자 확인
- 작업 내용 기기 내 자동 저장
- iPad의 넓은 화면에서는 사이드바와 편집 화면을 나란히 표시하고, 좁은 창에서는 탭 화면으로 전환
- 앱을 열면 시작 화면에서 새 프로젝트, 이전 작업 계속하기 또는 기존 JSON 가져오기를 선택
- 입력 화면에서 키보드 위의 **키보드 내리기** 버튼으로 입력 종료
- JSON 저장 시 버전 최신순 정렬, 날짜 `+09:00` 형식, 누락된 최소 iOS 버전 `16.1` 보정, NightFox GitHub 릴리스 URL의 프록시 주소 변환
- Project 탭과 JSON 미리보기에서 현재 JSON을 원하는 GitHub 저장소의 브랜치와 JSON 파일 경로에 업로드. 개인용 GitHub 토큰은 저장소별로 기기 키체인에 저장
- GitHub 업로드 중 전송량에 따른 0~100% 진행 막대를 표시하고 완료되면 팝업으로 결과 안내

## 사용법

1. **소스** 탭에서 이름을 입력합니다.
2. **앱** 탭에서 앱과 최소 하나의 버전을 추가합니다. 다운로드 URL은 게시된 IPA 또는 ADP 파일을 가리켜야 합니다. 크기는 바이트 단위입니다.
3. 필요하면 **뉴스**를 추가합니다.
4. **JSON** 탭에서 검증 메시지를 확인하고 **JSON 저장**을 누릅니다. 기존 JSON은 같은 탭의 **가져오기**에서 열 수 있고, **GitHub에 업로드하기**에서 바로 업로드 화면을 열 수 있습니다.
5. 저장소에 직접 반영하려면 **Project → GitHub에 업로드하기**에서 저장소(`소유자/저장소` 또는 GitHub URL), 브랜치, JSON 파일 경로를 입력합니다. 기본값은 `kes158/NightFox_Repository`, `main`, `NightFox.json`입니다. 화면 아래 **사용 방법**에 따라 GitHub의 Fine-grained personal access token을 만들고, 업로드할 저장소를 선택한 뒤 **Contents → Read and write** 권한을 부여합니다. 토큰을 입력하고 **JSON 업로드하기**를 누르면 기존 파일은 덮어쓰고 없는 파일은 새로 만듭니다. 토큰은 저장소별로 기기 키체인에서 다시 불러옵니다.

이 앱은 JSON 파일을 생성하고 선택한 비공개 GitHub 저장소에 업로드할 수 있습니다. 실제 IPA/ADP 파일은 사용자가 별도로 호스팅해야 SideStore 소스로 배포할 수 있습니다.

## 빌드와 설치

- Xcode에서 `Source.xcodeproj`를 엽니다.
- 배포 대상: iOS 17 이상.
- 앱 식별자가 `app.sourceeditor`로 변경되어 기존 설치본과 별개 앱으로 설치됩니다. 기존 작업은 이전 앱에서 JSON으로 저장한 뒤 새 앱에서 가져오세요. 저장소별 GitHub 토큰도 새 앱에서 다시 입력해야 합니다.
- 제공된 IPA는 코드 서명 및 프로비저닝이 없는 빌드입니다. SideStore 등에서 기기용으로 서명해 설치하거나 Xcode에서 자신의 개발 팀을 선택해 다시 빌드하세요.
- 터미널에서는 `./scripts/build-ipa.sh`로 서명되지 않은 IPA를 `build/Source.ipa`에 만들 수 있습니다.
- GitHub의 **Actions → Build Source Editor IPA → Run workflow**를 수동 실행하면 빌드 결과에 `Source_Editor.ipa` 아티팩트와 **iPhone/iPad Safari download** 링크가 표시됩니다. iPhone/iPad에서는 결과 화면의 링크를 눌러 비공개 저장소의 Release에서 IPA를 직접 받으세요. Actions의 아티팩트 미리보기 화면에서 파일을 저장하면 일부 환경에서 끝부분이 잘린 파일이 만들어질 수 있습니다.
- 수동 실행으로 만든 Release는 실행 번호마다 별도로 생성되며 비공개 저장소 안에만 표시됩니다. IPA는 서명되지 않았으므로 Feather로 서명한 뒤 설치해야 합니다. 파일의 생성일과 수정일은 다운로드하는 기기와 방식에 따라 다운로드 시각으로 표시될 수 있습니다.
- **Actions → Delete past runs and releases → Run workflow**를 수동 실행하면 완료된 워크플로 기록과 모든 Release, 각 Release에 연결된 태그를 삭제합니다. 실행 중인 정리 작업과 Release에 연결되지 않은 태그는 남습니다.

## 범위

온라인 이미지 업로드는 포함하지 않았습니다. IPA/ADP에서 추출한 아이콘은 로컬 초안에 미리보기용으로 저장되며 JSON에는 포함되지 않습니다. 가져온 JSON의 추가 필드는 편집 중에도 가능한 한 보존하며, NightFox 변환 규칙에서 제거하는 필드(`website`, `patreonURL`, `marketplaceID`, `buildVersion`, 뉴스 `url` 등)는 저장 결과에서 제외합니다.
